El nuevo entorno DEV del Marketplace B2B Carrefour está montado con backend Medusa/MercurJS desplegado en Render (plan free) sobre Docker, usando Supabase como base de datos PostgreSQL y Upstash como Redis gestionado, mientras que el frontend se conecta por HTTP al backend público en https://marketplace-b2b-backend-dev.onrender.com mediante MEDUSA_BACKEND_URL y autentica las rutas Store con NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY (header x-publishable-api-key); el estado operativo se valida por /health, y para pruebas del equipo se han preparado colección Postman, environments (Render/Local) y credenciales replicadas de desarrollo para acelerar la integración front-to-back.
